## IoT 与硬件通信

### 1. Web Serial

**主要技术:** Web Serial API

**功能:**

* 与 Arduino, Micro:bit 等串口设备进行有线通信。
* 发送模式: 发送一次, 连续发送, 以“名称:值”格式发送。
* 接收模式: 按换行符解析, 按逗号解析。
* 波特率设置 (9600 ~ 115200 baud)。
* 防止重复数据发送, 节流 (Throttling, 30ms)。

**主要积木:**

* `连接 Web Serial`
* `发送 [TEXT] 一次 (带换行)`
* `连续发送 [TEXT]`
* `接收到的数据 (读取一行)`
* `用 [DELIMITER] 分割接收到的数据`

**使用示例:**

```
连接 Web Serial
将波特率设置为 115200
发送 LED:ON 一次 (带换行)

```

---

### 2. Web Bluetooth

**主要技术:** Web Bluetooth API (BLE)

**功能:**

* 与 Micro:bit, Arduino, ESP32 等蓝牙设备进行无线通信。
* 自动识别设备类型 (Nordic UART, JDY-33, HM-10)。
* 20字节分块传输 (支持 BLE MTU)。
* 发送/接收协议与 Web Serial 相同。

**主要积木:**

* `连接到 [DEVICE_TYPE] 设备 (默认)`
* `连接设备 服务UUID [SERVICE] TX [TX] RX [RX]`
* `蓝牙是否已连接？`
* `连续发送 名称 [LABEL] : 值 [VALUE]`

**支持设备:**

* BBC micro:bit
* Arduino/ESP32 (Nordic UART)
* JDY-33/HM-10 (AT 模式)
* 所有其他 BLE 设备 (自动检测)

---

### 3. WiFi (WebSocket)

**主要技术:** WebSocket (ws:// / wss://)

**功能:**

* 与 ESP8266, ESP32 等 WiFi 设备进行 WebSocket 通信。
* 自动选择协议 (HTTPS 环境下使用 wss://)。
-流模式: 原始数据 (Raw) 传输, CSV 多重传输, 标签:值 传输。
* 节流 (Throttling) 50ms (比 Web Serial 更快)。

**主要积木:**

* `连接到位于 [IP]:[PORT] 的 WiFi 设备`
* `安全连接 [PROTOCOL] [ADDRESS]`
* `连续发送 [DATA] (Raw) (无换行)`
* `连续发送 [NUM_FIELDS] 个变量: [DATA]`

**使用示例:**

```
连接到位于 192.168.1.10:8080 的 WiFi 设备
连续发送 3 个变量: 100, 200, 300

```

### 4. ESP32-CAM 视频

**主要技术:** WebSocket + Python 桥接

**功能:**

* 在 Scratch 舞台上实时显示 ESP32-CAM 视频流。

* `加载 Q表 [JSON]`

**使用示例:**

```

传感器值 = 将传感器数组 [100,50,30] 转换为 3传感器模式
```

### 27. 画笔 (Pen)

**主要技术:** Canvas 渲染

**现有功能:**

* 落笔/抬笔。
* 设置画笔颜色/粗细。
* 图章。
* 全部擦除。

**⭐ 新增功能:**

#### 1. 基于坐标的直接绘图

直接使用坐标进行绘图，无需移动角色。

**主要积木:**

* `在 x:[X] y:[Y] 处画点` - 在特定坐标画点。
* `画线 从 x1:[X1] y1:[Y1] 到 x2:[X2] y2:[Y2]` - 在两点之间画线。
* `画角 x1:[X1] y1:[Y1] x2:[X2] y2:[Y2] x3:[X3] y3:[Y3] 存储在插槽:[SLOT]` - 连接三点画线并计算/存储角度 (插槽 1-6)。
* `从插槽:[SLOT] 获取角度` - 返回存储的角度值。

**使用示例:**

```
将画笔颜色设置为 #ff0000
画线 从 x1:0 y1:0 到 x2:100 y2:100
画角 x1:0 y1:0 x2:100 y2:0 x3:100 y3:100 存储在插槽:1
角度 = 从插槽:1 获取角度  // 返回 90 度

```

**应用:**

* 绘制数学图表。
* 绘制几何图形 (三角形, 正方形等)。
* 角度测量和可视化。

#### 2. 雷达可视化 (用于超声波传感器)

用于自动驾驶和机器人控制的雷达可视化功能。

**主要积木:**

* `雷达初始化 中心 x:[CX] y:[CY] 最大距离:[MAX_DIST] 角度范围:[ANGLE_RANGE]` - 初始化雷达。
* `雷达映射值 从 [MIN_VAL] 到 [MAX_VAL]` - 设置传感器值范围映射。
* `雷达绘制 角度:[ANGLE] 距离:[DISTANCE]` - 绘制雷达线 (检测区域为绿色，其余为红色)。
* `雷达淡出 [AMOUNT]%` - 雷达淡出效果 (残影效果)。

**使用示例:**

```
全部擦除
雷达初始化 中心 x:0 y:0 最大距离:180 角度范围:180
雷达映射值 从 0 到 400

// 当传感器值为 100 (0 度方向)
雷达绘制 角度:0 距离:100

// 使用淡出效果模糊之前的雷达线
雷达淡出 5%

```

**应用:**

* 超声波传感器可视化 (Arduino, Micro:bit)。
* 激光雷达 (LiDAR) 传感器可视化。
* 自动驾驶机器人的障碍物检测显示。

**雷达颜色规则:**

* **绿色:** 传感器检测到的距离范围内。
* **红色:** 从检测距离到最大距离范围 (无障碍物)。

### 28. 翻译 (Translate)

**主要技术:** Google Translate API + 多代理 (Multi-Proxy)

**现有功能:**

* 将文本翻译成各种语言。
* 检测当前项目语言。

**⭐ 新增功能:**

#### 多代理故障转移策略 (Multi-Proxy Failover Strategy)

**问题:**

* 以前: 使用单个代理 → 如果该代理宕机，翻译失败。
* 由于 CORS 策略，无法直接访问。

**解决方案:**

* 按顺序尝试 3 个 CORS 代理。
* 快速失败策略 (每个代理超时 4 秒)。
* 如果一个失败，自动尝试下一个。

**代理顺序:**

1. **corsproxy.io** - 最快 (首选)
2. **allorigins.win** - 稳定 (次级备份)
3. **codetabs.com** - 最终备份

**主要积木:**

* `将 [WORDS] 翻译为 [LANGUAGE]` - 翻译文本 (稳定性提高)。
* `语言` - 当前项目语言。

**改进:**

* ✅ 消除了单点故障。
* ✅ 显著提高了翻译成功率。
* ✅ 对代理宕机具有鲁棒性。
* ✅ 自动缓存 (对相同文本/语言的重复请求立即返回)。

**使用示例:**

```
翻译结果 = 将 [Hello] 翻译为 [中文]
// 结果: "你好"

翻译结果 = 将 [Hello] 翻译为 [日语]
// 结果: "こんにちは"

```

**支持语言:**
支持超过 100 种语言 (韩语, 英语, 日语, 中文, 法语, 西班牙语等)。
