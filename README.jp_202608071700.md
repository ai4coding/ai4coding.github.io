## IoT & ハードウェア通信

### 1. Webシリアル (Web Serial)

**主要技術:** Web Serial API

**機能:**

* Arduino, Micro:bit などのシリアルデバイスとの有線通信
* 送信モード: 1回送信, 連続送信, 「名前:値」形式での送信
* 受信モード: 改行区切りでの解析, カンマ区切りでの解析
* 通信速度設定 (9600 ~ 115200 baud)
* 重複データ送信防止, スロットリング (30ms)

**主要ブロック:**

* `Webシリアルを接続する`
* `[TEXT] を1回送信する (改行あり)`
* `[TEXT] を連続送信する`
* `受信データ (1行読む)`
* `受信データを [DELIMITER] で分割する`

**使用例:**

```
Webシリアルを接続する
速度を 115200 に変更する
LED:ON を1回送信する (改行あり)

```

---

### 2. Web Bluetooth

**主要技術:** Web Bluetooth API (BLE)

**機能:**

* Micro:bit, Arduino, ESP32 などのBluetoothデバイスとの無線通信
* デバイスタイプの自動認識 (Nordic UART, JDY-33, HM-10)
* 20バイトごとのチャンク分割送信 (BLE MTU 対応)
* 送受信プロトコルはWebシリアルと同一

**主要ブロック:**

* `[DEVICE_TYPE] デバイスに接続する (基本)`
* `サービスUUID [SERVICE] TX [TX] RX [RX] でデバイスに接続する`
* `Bluetoothは接続されているか？`
* `名前 [LABEL] : 値 [VALUE] を連続送信する`

**対応デバイス:**

* BBC micro:bit
* Arduino/ESP32 (Nordic UART)
* JDY-33/HM-10 (AT Mode)
* その他すべてのBLEデバイス (自動検出)

---

### 3. Wi-Fi (WebSocket)

**主要技術:** WebSocket (ws:// / wss://)

**機能:**

* ESP8266, ESP32 などのWi-FiデバイスとのWebSocket通信
* プロトコル自動選択 (HTTPS環境では wss://)
* ストリーミングモード: Raw送信, CSV多重送信, ラベル:値 送信
* スロットリング 50ms (Webシリアルより高速)

**主要ブロック:**

* `[IP]:[PORT] のWi-Fiデバイスに接続する`
* `[PROTOCOL] [ADDRESS] にセキュア接続する`
* `[DATA] (Raw) を連続送信する (改行なし)`
* `[NUM_FIELDS]個の変数を連続送信する: [DATA]`

**使用例:**

```
192.168.1.10:8080 のWi-Fiデバイスに接続する
3個の変数を連続送信する: 100, 200, 300

```

### 4. ESP32-CAM ビデオ

**主要技術:** WebSocket + Python ブリッジ

**機能:**

* ESP32-CAMのカメラ映像をScratchのステージにリアルタイム表示
* ローカルPythonブリッジプログラムを介したWebSocket通信
* 映像の反転, スナップショット保存機能

**主要ブロック:**

* `ブリッジプログラムのダウンロードサイトを開く`
* `ESP32-CAM エージェントに接続する`
* `ESP32-CAM ビデオ表示 [ON_OFF]`
* `ESP32-CAM スナップショットを保存する`

**機能:**

* Google Teachable Machineで学習した画像分類モデルを使用
* モデルURL入力によるカスタム分類器のロード
* 閾値設定 (0.0 ~ 1.0) による認識精度の調整

**主要ブロック:**

* `Teachable Machine サイトへ行く`
* `モデルのアドレスを [URL] に変更する`
* `閾値を [THRESHOLD] に変更する`
* `モデルを開始する`
* `認識結果`

**使用例:**

```
モデルのアドレスを https://teachablemachine.withgoogle.com/models/ABC123/ に変更する
閾値を 0.8 に変更する
モデルを開始する
もし (認識結果) = [猫] ならば
  「猫を発見！」と言う

```

### 8. 音声認識 (Speech Recognition)

**主要技術:** Web Speech API

**機能:**

* リアルタイム音声→テキスト変換 (Speech-to-Text)
* コマンド検出 (前進, 後退, 左, 右, 停止, 行け, 回転)
* 数値パラメータ抽出 (速度, 角度, 距離)
* 多言語対応 (韓国語, 英語, 日本語, 中国語など)
* 感情分析 (ポジティブ/ネガティブ/中立)

**主要ブロック:**

* `言語を [LANG] に設定する`
* `音声認識を開始する`
* `認識されたテキスト`
* `最後のコマンド`
* `検出された速度 (0-100)`
* `検出された角度 (度)`
* `< キーワード [WORD] が含まれているか？ >`
* `(感情)`

**使用例:**

```
言語を [ja-JP] に設定する
音声認識を開始する
もし (最後のコマンド) = [前進] ならば
  (検出された速度) の速さで前に移動する

```

### 9. 強化学習 自動運転 (Reinforcement Learning)

**主要技術:** Q-learning アルゴリズム

**機能:**

* Q-learning ベースの自動運転AIの実装
* センサー入力の離散化 (3センサー/6センサーモード)
* PID制御の統合
* 学習パラメータ調整 (学習率, 探索率, 割引率)
* Q-Table 保存/ロード (JSON)

**主要ブロック:**

* `AIの頭脳設定: 学習率 [ALPHA] 探索率 [EPSILON] 割引率 [GAMMA]`
* `センサー配列 [SENSORS] を3センサーパターンに変換する`
* `Q-learning: 状態 [STATE] 行動 [ACTION] 報酬 [REWARD] 次の状態 [NEXT_STATE]`
* `最適行動を返す: 状態 [STATE]`
* `Q-Table を保存 (ダウンロード)`
* `Q-Table を読み込む [JSON]`

**使用例:**

```
AIの頭脳設定: 学習率 0.1 探索率 0.2 割引率 0.9
センサー値 = センサー配列 [100,50,30] を3センサーパターンに変換する
行動 = 最適行動を返す: 状態 (センサー値)
Q-learning: 状態 (センサー値) 行動 (行動) 報酬 10 次の状態 (次のセンサー値)

```

### 27. ペン (Pen)

#### 1. 座標ベースの直接描画

スプライトを移動させずに座標を指定して直接描画します。

**主要ブロック:**

* `draw point at x:[X] y:[Y]` - 特定の座標に点を描く
* `draw line from x1:[X1] y1:[Y1] to x2:[X2] y2:[Y2]` - 2点間に線を引く

**使用例:**

```
draw line from x1:0 y1:0 to x2:100 y2:100
draw angle x1:0 y1:0 x2:100 y2:0 x3:100 y3:100 store in slot:1
角度 = angle from slot:1  // 90度を返す
```

#### 2. レーダー可視化 (超音波センサー用)

自動運転やロボット制御のためのレーダー可視化機能です。

**主要ブロック:**

* `radar init center x:[CX] y:[CY] max distance:[MAX_DIST] angle range:[ANGLE_RANGE]` - レーダー初期化
* `radar map value from [MIN_VAL] to [MAX_VAL]` - センサー値の範囲マッピング設定
* `radar draw at angle:[ANGLE] distance:[DISTANCE]` - レーダー線を描画 (検知部分は緑, 残りは赤)
* `radar fade by [AMOUNT]%` - レーダーフェード効果 (残像効果)

**使用例:**

```
すべて消す
radar init center x:0 y:0 max distance:180 angle range:180
radar map value from 0 to 400

// センサー値が100の場合 (0度方向)
```

**レーダー色ルール:**

### 28. 翻訳 (Translate)

**主要技術:** Google Translate API + Multi-Proxy

**既存機能:**

* テキストを様々な言語に翻訳
* 現在のプロジェクト言語を検出

**⭐ 新規追加機能:**

#### マルチプロキシ フェイルオーバー戦略 (Multi-Proxy Failover Strategy)

**問題点:**

* 従来: 単一プロキシを使用 → そのプロキシがダウンすると翻訳不可
* CORSポリシーにより直接アクセス不可

**解決策:**

* 3つのCORSプロキシを順次試行
* ファストフェイル戦略 (各プロキシ4秒タイムアウト)
* 1つが失敗すると自動的に次のプロキシを試行

**プロキシ順序:**

1. **corsproxy.io** - 最速 (優先試行)
2. **allorigins.win** - 安定 (2次バックアップ)
3. **codetabs.com** - 最終バックアップ

**主要ブロック:**

* `translate [WORDS] to [LANGUAGE]` - テキスト翻訳 (安定性向上)
* `language` - 現在のプロジェクト言語

**改善事項:**

* ✅ 単一障害点 (Single Point of Failure) の排除
* ✅ 翻訳成功率の大幅な向上
* ✅ プロキシのダウンタイムに対する堅牢性
* ✅ 自動キャッシング (同一テキスト/言語の繰り返しリクエスト時は即時返却)

**使用例:**

```
翻訳結果 = translate [こんにちは] to [English]
// 結果: "Hello"

翻訳結果 = translate [Hello] to [Japanese]
// 結果: "こんにちは"

```

**対応言語:**
100以上の言語に対応 (韓国語, 英語, 日本語, 中国語, フランス語, スペイン語など)
