🔐 API 키 보안 — 꼭 읽어주세요!

🚨
API 키는 비밀번호와 같습니다!
다른 사람이 내 키를 사용하면 내 할당량이 소진되고, 유료 전환 시 내 계정에 요금이 청구될 수 있습니다. 절대 다른 사람에게 공유하지 마세요.

이 확장블록의 보안 설계

  • sessionStorage 저장: 탭을 닫으면 자동 삭제, 새로고침 시 유지됩니다
  • 헤더 전송: API 키가 URL에 노출되지 않도록 HTTP 헤더로만 전송합니다
  • 프로젝트 저장/공유 시 키 제외: .sb3 파일에 API 키가 절대 포함되지 않습니다
  • 서버 미저장: 키는 여러분의 브라우저 안에서만 존재합니다. Brixel AI 서버로 전송되지 않습니다
  • 5초 쿨다운: 무료 쿼터 보호를 위해 요청 간 5초 간격이 자동 적용됩니다

🖥️ 공용 컴퓨터(학교/도서관/PC방) 사용 시

  1. 사용 시작 전 공용 컴퓨터 모드 [켜기] 블록을 먼저 실행하세요
    → API 키가 어디에도 저장되지 않습니다 (메모리에만 유지)
  2. 사용이 끝나면 반드시 API 키 삭제하기 블록을 실행하세요
  3. 가능하면 브라우저 시크릿/비공개 모드에서 사용하세요

🛡️ API 키가 노출되었다면?

  1. 즉시 Google AI Studio에 접속합니다
  2. 노출된 API 키를 삭제(Delete)합니다
  3. "API 키 만들기"로 새 키를 발급받습니다
  4. 새 키를 블록에 다시 등록합니다

※ 키 재발급은 무료이며 즉시 가능합니다. 노출이 의심되면 바로 교체하세요.

주의사항 체크리스트

  • API 키를 친구나 다른 사람에게 알려주지 않기
  • API 키를 채팅, SNS, 이메일로 보내지 않기

  • 공용 컴퓨터에서는 반드시 "공용 컴퓨터 모드" 켜기
  • 사용 후 공용 컴퓨터에서는 "API 키 삭제하기" 실행
  • 과도한 반복 질문(무한루프 안에서 AI 질문)은 할당량을 빠르게 소진
  • AI의 답변은 항상 정확하지 않을 수 있음 — 중요한 정보는 확인 필요
  • 안전 필터가 부적절한 질문을 차단할 수 있음 — 이는 정상 동작

자주 묻는 질문

Q. 돈이 들지 않나요?

무료 할당량 안에서 사용하면 비용이 발생하지 않습니다. Google은 무료 사용자에게 신용카드를 요구하지 않습니다. 유료 전환은 사용자가 직접 결제 수단을 등록해야만 가능하므로, 자동으로 과금되지 않습니다.

Q. 탭을 닫으면 키가 사라지나요?

네, 탭을 닫으면 API 키가 완전히 삭제됩니다. 새로고침(F5)만 하면 키가 유지되므로 수업 중에는 편하게 사용할 수 있습니다. 탭이나 브라우저를 닫으면 다음에 다시 입력해야 합니다. 공용PC 모드에서는 어디에도 저장되지 않습니다.

Q. Groq는 뭔가요?

Groq는 Gemini의 대체 AI 서비스입니다. 무료 할당량이 일일 14,400회로 매우 넉넉합니다. Gemini 한도가 소진되었을 때 Groq 모델로 전환하면 계속 사용할 수 있습니다. console.groq.com에서 무료 키를 발급받으세요.

Q. 여러 학생이 같은 키를 쓸 수 있나요?

가능하지만 권장하지 않습니다. 할당량이 공유되어 금방 소진되고, 키가 여러 기기에 노출되면 보안 위험이 커집니다. 학생마다 자기 Google 계정으로 키를 발급받는 것이 가장 안전합니다.

Q. 어떤 모델을 선택해야 하나요?

Gemini Flash-Lite가 가장 넉넉합니다 (1,000회/일). 더 똑똑한 답변이 필요하면 Flash나 Pro를 선택하세요. Gemini 한도가 부족하면 Groq Llama 3.3 70B(14,400회/일)로 전환하면 됩니다.

Q. "안전 필터에 의해 차단되었습니다" 메시지가 뜹니다

Google의 안전 필터가 부적절하다고 판단한 질문을 차단한 것입니다. 이 확장블록은 K-12 학생 보호를 위해 가장 엄격한 안전 설정을 적용하고 있습니다. 질문 내용을 바꿔서 다시 시도해보세요.

🔐 API Key Security — Must Read!

🚨
Your API key is like a password!
If someone else uses your key, your quota gets consumed, and if you ever switch to paid, charges go to your account. Never share your key with anyone.

How This Extension Protects Your Key

  • Encryption: Your key is encrypted with AES-GCM 256-bit before storage
  • Session-only storage: Stored in sessionStorage only — automatically deleted when you close the tab or browser
  • Header transmission: Key is sent via HTTP header (not exposed in URL)
  • Not saved in projects: Your key is NEVER included when saving or sharing .sb3 files
  • No server storage: Your key exists only in your browser. It is never sent to Brixel AI servers

🖥️ Using a Shared/Public Computer (School, Library)?

  1. Before starting, run Shared Computer Mode [ON]
    → Your key will NOT be stored anywhere (memory only)
  2. When finished, always run Delete API Key
  3. If possible, use the browser's Incognito/Private mode

🛡️ If Your Key Gets Exposed

  1. Go to Google AI Studio immediately
  2. Delete the exposed API key
  3. Click "Create API Key" to get a new one
  4. Enter the new key in the block

※ Re-issuing a key is free and instant. Replace immediately if you suspect exposure.

Safety Checklist

  • Never share your API key with friends or others
  • Never send your API key via chat, social media, or email
  • Never put your API key in visible blocks like "say" or "think"
  • Always enable "Shared Computer Mode" on public/school computers
  • Always run "Delete API Key" when done on shared computers
  • Avoid putting AI questions inside infinite loops — this drains quota fast
  • AI answers may not always be accurate — verify important information
  • The safety filter may block inappropriate questions — this is normal
✅
Don't worry: Your API key is NEVER included when you save or share a project. Anyone who opens your shared project will need to enter their own API key.

Frequently Asked Questions

Q. Will I be charged?

No, as long as you stay within the free quota. Google does not require a credit card for free tier access. Paid billing only activates if you manually register a payment method — there is no automatic charge.

Q. Will my key disappear if I close the tab?

In Personal PC mode, your encrypted key persists within the same browser session. Closing the browser entirely removes it. In Shared PC mode, the key exists only in memory and vanishes the moment you close the tab.

Q. Can multiple students share one key?

Technically yes, but not recommended. The quota is shared and will run out quickly, and exposing the key across multiple devices increases security risk. Each student should create their own key with their Google account.

Q. Which model should I choose?

Flash-Lite gives the most room (1,000 req/day) and is great for regular classroom use. Choose Flash or Pro when you need smarter answers for advanced projects.

Q. I'm getting "Blocked by safety filter" messages

Google's safety filter blocked the question. This extension uses the strictest safety settings to protect K-12 students. Try rephrasing your question.
